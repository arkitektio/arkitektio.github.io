[UC2](https://www.youtube.com/watch?v=Jp5TOqvf7Nc) is an open-source, modular microscope system,
usually controlled by [ImSwitch](https://github.com/openUC2/ImSwitch). ImSwitch ships an Arkitekt panel
that registers the microscope as an app: notebooks, other apps and workflows can then call it, and
its images land in [Mikro](/docs/develop/internals/mikro).

<Callout type="warn" title="ImSwitch pins its own client">

ImSwitch uses the `arkitekt` client 16 (`pip install "arkitekt[rekuest,mikro]==16.0.1"`), not the
version 19 these docs describe. Check
[ImSwitch's Arkitekt notes](https://github.com/openUC2/ImSwitch/blob/master/docs/ARKITEKT.md) for
the server versions it needs.

</Callout>

## Bind the microscope

1. Install the client in ImSwitch's environment. Without it, ImSwitch starts normally and the panel
   says what to install.
2. List the `"Arkitekt"` widget in your setup's `availableWidgets`, switch it on in ImSwitch's App
   Manager and open the panel (System category).
3. Enter the server's address and click **Bind microscope**.
4. Open the approval link on any computer, sign in, pick the hub and approve the app.

The login is stored on the microscope, so later starts reconnect without approval. **Unbind**
removes it.

## What you can call

| Action | What it does |
|---|---|
| Get Stage Position, Move Stage, Go To XY, Home Axis | Move the stage, in µm |
| Move To Sample Loading Position | Park the stage for loading |
| Set Illumination, Set Camera | Light on/off and intensity, exposure and gain |
| Acquire Frame | Take one frame and store it in Mikro, placed in stage space |
| Run Tile Scan | Scan a grid into one image and upload it to Mikro |

Actions that move or acquire share one `microscope` lock, so they run one at a time, and they are
refused while ImSwitch runs an experiment, a recording or a workflow. The stage position, light and exposure are
published as live state.

The panel settings, unattended login with a mandate key, and running a hub on the microscope's own
computer are described in [ImSwitch's Arkitekt notes](https://github.com/openUC2/ImSwitch/blob/master/docs/ARKITEKT.md).
