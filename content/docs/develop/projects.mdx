Arkitekt is spread over many repositories, most of them in the
[arkitektio](https://github.com/orgs/arkitektio) organization. You will only touch a few. If you
do not know which one a problem belongs to, open an issue on the
[documentation repository](https://github.com/arkitektio/arkitektio.github.io/issues) and we will
point you to the right place.

## Services

Each service is described under [Services](/docs/develop/internals).

| Repository | What it is |
|---|---|
| [lok-server](https://github.com/arkitektio/lok-server) | Lok: users, apps, login and configuration (Fakts) |
| [rekuest-server](https://github.com/arkitektio/rekuest-server) | Rekuest: the catalogue of actions and task assignment |
| [rekuest-agentd](https://github.com/arkitektio/rekuest-agentd) | The server side of the agent protocol, in Rust |
| [fluss-server](https://github.com/arkitektio/fluss-server) | Fluss: workflows and the logs of their runs |
| [mikro-server](https://github.com/arkitektio/mikro-server) | Mikro: microscopy data and its metadata |
| [kraph-server](https://github.com/arkitektio/kraph-server) | Kraph: the knowledge graph |
| [kabinet-server](https://github.com/arkitektio/kabinet-server) | Kabinet: the app store, and deployed apps |
| [elektro-server](https://github.com/arkitektio/elektro-server) | Elektro: electrophysiology data and simulations |
| [alpaka-server](https://github.com/arkitektio/alpaka-server) | Alpaka: LLMs and chat, through Ollama |
| [lovekit-server](https://github.com/arkitektio/lovekit-server) | Lovekit: WebRTC streams and rooms |
| [omero-ark-server](https://github.com/arkitektio/omero-ark-server) | OmeroArk: access to an OMERO server |
| [kluster-server](https://github.com/arkitektio/kluster-server) | Kluster: Dask clusters on demand (optional) |

The services share three [backend libraries](/docs/develop/internals/backend-libraries):
[kante](https://github.com/arkitektio/kante),
[authentikate](https://github.com/arkitektio/authentikate) and
[koherent](https://github.com/arkitektio/koherent).

## Contributing [#contributing]

- **Report a bug or ask for a feature** on the repository it belongs to, or on the
  [documentation issues](https://github.com/arkitektio/arkitektio.github.io/issues) if you are not
  sure.
- **Point out an error in these docs** with an issue or a pull request on the
  [documentation repository](https://github.com/arkitektio/arkitektio.github.io). Marking a passage
  as unclear is enough.
- **Work on a project.** Build an app first to see what you would change, then pick the repository
  above.
- **Talk to us.** There are no regular meetings yet. Reach out on GitHub or by
  [email](mailto:johannes.roos@jku.at).
