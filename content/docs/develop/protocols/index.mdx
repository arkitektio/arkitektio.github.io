The [Python](/docs/develop/python), [Rust](/docs/develop/first-rust-app) and
[Kotlin](/docs/develop/kotlin) clients wrap two protocols, both JSON. Use these pages to write a
client in another language, to debug one, or to see what the libraries do for you.

| Protocol | Transport | What it is for | When it is used |
|---|---|---|---|
| **[Fakts](/docs/develop/protocols/fakts)** | HTTP | Discovery, device authorization, token refresh, service addresses | Once at startup, then to refresh the token |
| **[Agent protocol](/docs/develop/protocols/agent)** | WebSocket to Rekuest | Registration, tasks, state | For as long as an app offers actions |

A script that only calls the platform needs Fakts and the services'
[GraphQL](/docs/develop/internals/graphql) APIs, and no agent.

## The flow

The app presents its manifest to Lok, a person approves it, and the app receives a token and the
addresses of the services it asked for. With those it opens the agent socket to Rekuest.

```text
   app                         Lok (Fakts)                      Rekuest
    │                               │                               │
    │ 1. discover, present manifest │                               │
    │ ─────────────────────────────►│                               │
    │        a person approves      │                               │
    │ ◄─────────────────────────────│                               │
    │   token + service addresses   │                               │
    │                               │                               │
    │ 2. open  wss://…/agi   REGISTER{token, declaration}           │
    │ ─────────────────────────────────────────────────────────────►│
    │ ◄──────────────────────────────────────────────────── INIT    │
    │ ◄──────────────────────────────────────────────────── ASSIGN  │
    │ ─── YIELD, COMPLETED ────────────────────────────────────────►│
```

The agent always dials out. It opens no port and needs no public address, so an app runs unchanged
behind a firewall, in a container or on a microcontroller.

## Concepts on the wire

Everything in the [shared concepts](/docs/develop/shared-concepts) maps to frames on the
agent socket:

| Concept | On the wire |
|---|---|
| The app and its actions | The declaration in the first frame, `REGISTER` |
| A task | An `ASSIGN` from the server, answered with `YIELD` and `COMPLETED` |
| Progress, logs, pause, cancel | Further frames about the same task |
| State | `STATE_PATCH` frames, one per change |
| Bloks | Part of the declaration |
| Calling other actions | Child tasks requested over the same socket |

State, locks, bloks and shelved memory are optional. An agent that sends none of them is still
complete.

## Reference implementations

| Repository | What it is |
|---|---|
| [`rekuest-protocol`](https://github.com/arkitektio/arkirust/tree/main/crates/rekuest-protocol) | Every frame as Rust types, `no_std`. Its `agent_wire_examples.json` holds a canonical example of each frame, generated by the server. |
| [`rekuest-agentd`](https://github.com/arkitektio/rekuest-agentd) | The server side of the agent socket, with the design documents and a black-box conformance suite you can run a new agent against. |
| [`AgentProtocol.kt`](https://github.com/arkitektio/arkitekt-kotlin/blob/main/src/main/kotlin/live/arkitekt/AgentProtocol.kt) | The smallest complete client: one file, actions only. A good template for a new language. |
