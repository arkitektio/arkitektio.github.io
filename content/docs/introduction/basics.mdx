## Basics

Arkitekt is a software platform for bioimage analysis that acts as a [middleman](/docs/design/philosophy/middleman) between your data, your analysis tools and the people using them. Tools connect to Arkitekt rather than to each other, and data flows through it instead of being copied around. Arkitekt wants to be the central hub that connects your data and your image analysis tools.


As such, Arkitekt comes with an installable **Hub** that runs in the background on your computer and provides
a programming interface for apps to hook into. This Hub stores your data and routes requests between your image analysis tools, but does not do any image analysis itself. This is the purpose of **Apps**. What exactly the hub is (and is not) is spelled out in [The Hub](/docs/design#the-hub).

You can use your exisiting and familiar bioimage apps like [Fiji](/docs/apps/standalones/imagej-plugin),or [Napari](/docs/apps/standalones/mikro-napari) to connect to the Arkitekt Hub and get the data you need to analyze. However hopefully most of the time you will be using the Arkitekt Hub through a its [own graphical interface](/docs/apps/standalones/orkestrator) to explore your data and then only offload the analysis to your favorite image analysis tool. 



For most users, this is all you need to know about the software design of Arkitekt. You install it, and then you can use it to run image analysis tools. The rest of this section is intended for more technically
inclined users who want to know more about the inner workings of Arkitekt. If you are not interested in that, you can safely skip to the next section, please make sure to read a little bit in the design
section or go through our tutorial to get a better understanding of how to use Arkitekt.

<Callout type="info">


While Arkitekt comes with a graphical interface, it is not a requirement to use it. Arkitekt can be used entirely through its programming interface, and you can even build your own graphical interface if you want to.
Indeed there is nothing special about the prebuilt Arkitekt interface, for all intents and purposes it is just another App that connects to the Arkitekt server.


</Callout>
