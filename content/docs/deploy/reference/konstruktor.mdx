## What Konstruktor is [#konstruktor]

Konstruktor is the installer and admin tool for the Arkitekt platform. It is **one product with two
front ends**: a desktop app and a `konstruktor` command line tool. Both do exactly the same things,
authoring a hub, generating its Docker Compose project, authorizing it against a coordination server,
and driving Docker, because both are thin layers over the same core. They also share the same list
of known deployments, so a hub created in the app shows up in the CLI and the other way round.

Konstruktor creates two kinds of deployment:

- A **hub**: the data and compute services of Arkitekt, behind one gateway. This is what "installing
  Arkitekt" means, and what [Install your first hub](/docs/deploy/tutorials/first-hub) is about.
- A **plugin engine**: a single container that runs the plugins an organization installs, on this
  machine. See [Plugin engines](/docs/deploy/guides/plugin-engine).

Whatever it creates is an **ordinary Docker Compose project in a folder you choose**. There is no
Python, no helper container and nothing hidden: you can open the folder, read the compose file, and
run `docker compose` against it yourself if you ever want to.

Inside the deployment folder you will find `hub_config.yaml` (the hub profile: coordination server,
services, ports, image tags), the generated `docker-compose.yaml`, a `configs/` folder with one file
per service plus the gateway's `Caddyfile`, and `hub_credentials.json` holding the secrets. Edit the
compose file if you need to; Konstruktor keeps a `.bak` on every save.

## Download

Konstruktor is available for Windows, macOS and Linux. Docker, or a Docker-compatible engine, is its
only dependency. Pick your platform below, or grab a build from the
[releases page](https://github.com/arkitektio/konstruktor/releases/latest) on GitHub.

## Usage

How to install and run a hub with Konstruktor, in the app or from the terminal, is described step by
step in [Install your first hub](/docs/deploy/tutorials/first-hub). If something does not
work, see [Troubleshooting the startup](/docs/deploy/guides/troubleshooting).
