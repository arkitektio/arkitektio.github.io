## Orkestrator

The desktop app you use Arkitekt with: sign in, browse your data, run actions and workflows. No
admin rights needed. More in [Orkestrator](/docs/guides/apps/orkestrator).

<OrkestratorGrid pokket />

## Konstruktor

The desktop app that installs and runs a hub. Its only dependency is Docker, or a
Docker-compatible engine. More in [Konstruktor](/docs/get-started/deployment/konstruktor), or set up a hub step by
step in [Install your first hub](/docs/get-started/deployment/first-hub).

<DownloadGrid />

Prefer the terminal? `curl -fsSL https://raw.githubusercontent.com/arkitektio/konstruktor/main/install.sh | sh`
installs the command-line version; see [Install from the command line](/docs/get-started/deployment/install-cli).
