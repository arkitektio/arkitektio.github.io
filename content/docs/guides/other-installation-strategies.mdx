These are not recommended for beginners, but are useful if you want to integrate the platform into a
larger infrastructure or take part in its development.

## Edit what Konstruktor generated [#custom-compose]

Because a hub is a plain Docker Compose project, the simplest customization is to let Konstruktor
generate it and then edit `docker-compose.yaml` and the files in `configs/` yourself, from the
dashboard's **Edit compose file** or with any editor. Konstruktor keeps a backup of the previous
version on each save.

## Docker-Compose [#docker-compose]

If you prefer to start from a maintained compose configuration rather than a generated one, we keep
one at [arkitektio/arkitekt-server](https://github.com/arkitektio/arkitekt-server). It includes the
most common services and, when cloned with `git clone --recurse-submodules`, their source code. If you
run into problems with it, please open an issue in that repository.

## Helm Charts [#helm-charts]

We are working on a Helm chart for installing Arkitekt on a Kubernetes cluster; it will live at
[arkitektio/arkitekt-helm](https://github.com/arkitektio/arkitekt-helm). Until then the compose
configuration can be converted with [kompose](https://kompose.io/).

From here be dragons. You can find hints in the developer section of each service and in each
