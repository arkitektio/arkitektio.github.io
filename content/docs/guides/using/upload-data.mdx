You need Orkestrator connected to a hub ([Connect with Orkestrator](/docs/get-started/join/connect)).
To try it with sample data, download [cells1.TIF](/demos/cells1.TIF) and
[cells2.TIF](/demos/cells2.TIF).

## Upload files

Drag files from your computer into Orkestrator. You can drop several at once. Any file type and
size is accepted; Orkestrator detects the type and shows it in the file list on the left.

<video autoPlay muted loop controls className="rounded-md" width={"100%"}>
  <source src="/docs/introduction/first_steps/upload.webm" />
</video>

An uploaded file is stored as a file. To work with it as an image, run a converter action on it.
The App Store has converters for OME-TIFF, LIF, ND2, OBF and anything Bio-Formats reads.

## Sort them into Datasets

A **Dataset** groups data like a folder.

1. Click **Create Dataset** in the action bar, type a name and press Enter.
2. Drag files onto the Dataset to move them into it.
3. To upload straight into a Dataset, open it and drop the files there.

## Find what you can do with an item

While you drag an item, Orkestrator shows what you can do with it:

- Over the item itself: actions on that item, such as **Delete** or **Download**.
- Over another item: actions that combine the two, such as moving a file into the Dataset you hover
  over.

These come in two kinds:

| Kind | Where it comes from | Examples |
|---|---|---|
| **Manage actions** | Built into the platform, always available | Delete, download, move to a Dataset |
| **Tool actions** | The [actions](/docs/concepts/terminology#what-is-an-action) of the apps running on your hub | Thresholding, segmentation, conversion |

You do not have to drag. Right-click an item for the actions on it, or open the command menu with
**Ctrl+M** (**Cmd+M** on macOS) to reach almost every command from the keyboard. Both work with a
screen reader.
