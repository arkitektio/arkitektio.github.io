The connecting direction needs much less than building an app: a login, and then GraphQL. That
makes it the easiest place to use Arkitekt from a language without a full client.

## Rust

The Rust client has the same shape as Python's `connect(Mikro)`: declare a script app with the
services it uses, connect, and take the clients.

```rust
use mikro::{axes_for, Mikro};
use ndarray::ArrayD;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let rt =
        arkitekt::connect(arkitekt::easy("rusty-script", "0.1.0").service(mikro::service)).await?;
    let mikro = rt.require::<Mikro>()?;

    let data: ArrayD<f32> = ArrayD::from_shape_fn(vec![64, 64], |ix| (ix[0] * ix[1]) as f32);
    let image = mikro.create_array_dataset("gradient", &data, axes_for(&["y", "x"])).await?;
    println!("created {}", image.id);
    Ok(())
}
```

For operations the crate does not wrap, `mikro.rath()` gives the authenticated GraphQL client. See
the [Rust guide](/docs/guides/rust#services-and-scripts).

## Any language

Every service is a GraphQL API, and the login is plain HTTP. A client in any language needs two
steps:

1. **Log in with the Fakts protocol.** Discover the deployment, register the app, let a person
   approve it with the device-code flow (or present a mandate key), and receive tokens and the
   addresses of the services. See [Service discovery](/docs/concepts/services/service-discovery) and the
   [Fakts protocol](/docs/reference/protocols/fakts).
2. **Talk GraphQL to the services.** With the access token, query and mutate Mikro, Kraph,
   Rekuest and the others like any GraphQL API. Each publishes its schema, so a code generator for
   your language can give you typed queries. See [GraphQL](/docs/concepts/services/graphql).

That is enough for scripts, dashboards and integrations. Only an app that **offers** actions also
needs the agent socket: see [Protocols](/docs/reference/protocols).
