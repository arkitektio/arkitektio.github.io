An action can be a plain `def` or an `async def`. Arkitekt itself is async: the agent runs on an
event loop. What lets a sync function take part is [koil](https://github.com/jhnnsrs/koil), a small
bridge between sync and async code that `arkitekt` installs for you. You only need this page when
you write long-running sync actions or mix the two styles.

## How a sync action runs

An `async def` action runs on the agent's event loop. A sync action is handed to a worker thread,
so it does not block the agent while it computes or waits on a blocking library.

That thread is the reason cancellation differs between the two:

| | Cancelled |
|---|---|
| `async def` action | at its next `await` |
| sync action | at its next `koil.check_cancelled()` or `koil.sleep(...)` |

A thread cannot be stopped from outside. A sync task that never reaches one of these calls runs to
its end, even after it was cancelled.

## Make a sync action cancellable

Call `koil.check_cancelled()` wherever stopping is safe, typically once per iteration of a loop. It
does nothing while the task is wanted and raises once the task was cancelled:

```python
import koil
from arkitekt import App

app = App("scanner", "0.1.0")


@app.action
def scan(positions: int = 100) -> int:
    """Scan

    Visits {{positions}} positions, and stops between two of them when cancelled.
    """
    for i in range(positions):
        koil.check_cancelled()   # raises here if the task was cancelled
        move_and_acquire(i)      # your blocking code
    return positions
```

Let the exception pass. If you need to clean up, use `try`/`finally` and do not swallow it.

To wait, use `koil.sleep(seconds)` in place of `time.sleep`. It wakes up as soon as the task is
cancelled, and outside of a task it behaves like `time.sleep`.

## Call async code from a sync action

Every Arkitekt client and task method comes in both forms, `x(...)` and `await ax(...)`, so you
rarely bridge by hand. When you have an async function of your own, or of another library, call it
from sync code with `unkoil`. It runs the coroutine on the agent's loop and blocks until the result
is there:

```python
from koil import unkoil


async def fetch_settings(name: str) -> dict:
    ...


@app.action
def configure(name: str) -> None:
    """Configure"""
    settings = unkoil(fetch_settings, name)   # pass the function and its arguments, not a coroutine
    ...
```
