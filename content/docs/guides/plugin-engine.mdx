A **plugin engine** is the second thing Konstruktor can create: one container that runs the plugins
an organization has installed, on the machine where the engine lives. It is how a lab adds compute
to a hub without touching the hub itself. Choose **Plugin engine** in the app, or run:

```bash
konstruktor engine create ~/MyEngines/gpu-box --server go.arkitekt.live --identifier gpu-box
```

Engines are authorized against the coordination server the same way hubs are.
