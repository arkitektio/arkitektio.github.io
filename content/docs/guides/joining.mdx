If someone already runs an Arkitekt server for you, there is no server to install. You need the
**Orkestrator** desktop app, which is the user interface to any Arkitekt server,
it requires no admin rights and is available for Windows, MacOS, and Linux. You can use it to connect to any Arkitekt server you have access to.

1. Create your account on [go.arkitekt.live](https://go.arkitekt.live), or sign in if you have one.
   Ask the person running the server to add you to their organization.
2. [Install Orkestrator](/docs/guides/apps/orkestrator#desktop-application) for your operating
   system.
3. Open it, sign in with your account, and pick their server from the list. Servers your
   organization has authorized show up automatically; one that lives on another network is reached
   through the [mesh](/docs/concepts/security/mesh), and you can always enter its address by hand.

From there, continue with the [first steps](/docs/tutorials/absolute-basics).

<Callout type="warn" title="Wait, I need an account?">

No. You can run Arkitekt without ever talking to us: point Konstruktor at your institute's own
coordination server, or [self-host everything](/docs/concepts/topology#three-ways-to-meet),
coordinator included, and stay fully offline. The account just makes things easier: go.arkitekt.live
is a [coordinator](/docs/concepts/security/identity) we already run, so there is nothing extra to
operate and the [mesh](/docs/concepts/security/mesh) works across networks out of the box. It stores
only what a login needs (see the [privacy policy](/docs/privacy#tier-2-an-account-on-goarkitektlive)),
and your data and compute never go through it. If you would rather not, read
[Where Arkitekt runs](/docs/concepts/topology) for the trade-offs and pick the
**Another server** option in Konstruktor.

</Callout>
