`mikro-napari` is a napari plugin that connects your local [napari](https://napari.org) to
Arkitekt. Once connected, Orkestrator and workflows can show images and ROIs from your hub in
napari, and napari layers can be uploaded back.

### Installation

Mikro-Napari supports napari 0.4.17 and above. Install it in one of two ways:

- **From the command line (recommended).** In a Python environment (Python > 3.9):

  ```bash
  pip install mikro-napari
  pip install napari==0.4.17 pyqt5 # if you do not have napari installed yet (tested with 0.4.17; 0.4.18 should also work)
  ```

  Then start napari with the plugin:

  ```bash
  mikro-napari
  ```

- **From the [napari plugin store](https://napari-hub.org/plugins/mikro-napari).** This also works
  with the bundled napari app.

The napari plugin specification is changing quickly, so for now we follow napari's advice and
recommend the pip-installed napari over the bundled one.

### Usage

For a guided first run, see [Open your data in napari and Fiji](/docs/get-started/next-steps/napari-and-fiji).

The plugin does nothing until you connect it. You connect through the **Magic Bar**, the widget in
the bottom left corner. Most Arkitekt apps use the same widget.

<video autoPlay muted loop controls className="rounded-md" width={"100%"}>
  <source src="/docs/apps/standalones/open_napari.webm" />
</video>

1. On first use, the Magic Bar shows a connection screen. A hub on your computer, and hubs you
   reach through the [mesh](/docs/concepts/security/mesh), are detected and listed. For any other
   hub, enter its URL.
2. A browser opens and you approve the app, as you did for Orkestrator (see
   [Connect with Orkestrator](/docs/get-started/join/connect)).

The Magic Bar then shows the connection status. You can disconnect at any time and use napari as
before.

### Show an image in napari

Mikro-Napari does not call other apps from napari. You start actions in Orkestrator, which also
lets you build workflows that end in napari, such as
[Bridging deep learning](/docs/guides/using/deep-learning).

To show an image, run the **Show on Napari** action on it in Orkestrator. It appears in the bottom
right corner of the image pane. Leave **Show ROI Layer** on to also see the ROIs you drew in
Orkestrator.

<video autoPlay muted loop controls className="rounded-md" width={"100%"}>
  <source src="/docs/apps/standalones/napari_visualize.webm" />
</video>

- **Lazy loading.** Only the parts of the image you look at are downloaded.
- **ROIs sync live.** ROIs you mark on the ROI layer sync with the hub, with Orkestrator and with
  other napari instances connected to the same hub.
- **Changes stay in napari.** Edits to the image are not written back. Use the **Upload to
  Arkitekt** action to save them to the hub.
