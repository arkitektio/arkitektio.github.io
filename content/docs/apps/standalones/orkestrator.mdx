Orkestrator is the current primary user-interface for the Arkitekt platform, and is the recommended way to interact with the platform
to create and manage workflows, inspect and comment on your data, ... etc.

## Getting Started

Orkestrator is a **desktop application**, built on Electron. It is not a website and there is no browser version: you
download it once, install it, and it connects to any Arkitekt hub you have access to, on your own machine, in your lab
network, or across the internet through the [mesh](/docs/design/security/mesh).

### Desktop Application

Orkestrator is available for Windows, MacOS and Linux. Because it runs as a native app rather than inside a browser, it
can do a few things a web page never could:

- **Automatic Network Configuration**: Orkestrator finds Arkitekt instances you have connected through the
  [mesh](/docs/design/security/mesh) and connects to them. You do not have to enter the address of the instance you want
  to talk to, and you can switch between instances at any time.

- **Connect to unsecure instances**: Orkestrator can connect to Arkitekt instances that are not using HTTPS. This is useful when
  you are planning to use Arkitekt only in a local network, where certificates are not available. Note that you should not connect to unsecure instances
  that are exposed to the internet. Please refer to the [security](/docs/design/security/measures) section for more information.

- **Local GPU and memory**: the volume viewer and the other heavy views render on your machine, with your GPU and your
  memory budget, rather than inside a browser sandbox.

Features on the way:

- **Automatic Updates**: Orkestrator will in the future automatically check for updates and install them when available, so you always
  have the latest version without downloading it by hand.

- **Export and Import of Data**: While you can use Orkestrator to export and import data manually at this point, we are planning to bridge the [Gucker](./gucker)
  functionality directly into the desktop app, so you can export and import data without a separate application.

- **Deep Linking**: Orkestrator will in the future support deep linking, so you can share links to specific workflows, comments, ... etc.
  with other users and link to specific parts of the app from other applications.

<Callout type="info" title="Why a desktop app and not a website?">


Browsers are very restrictive in what they allow a web page to do, and this is especially true when it comes to networking:
a page served from the internet is not allowed to talk to a server in your lab network, to an instance without a valid
certificate, or to hardware on your machine. Those are exactly the things a bioimage analysis frontend needs. A desktop app
has none of these restrictions, so Orkestrator has always been one. If you want to learn more about the state of the open
web, we recommend reading [just the latest articles](https://www.eff.org/search/site/browser) by the EFF.


</Callout>
