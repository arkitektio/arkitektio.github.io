Konstruktor is the installer and admin tool for the Arkitekt platform. It creates a hub (or a plugin
engine) as an ordinary Docker Compose project, authorizes it against a coordination server, and then
lets you start, stop, update, back up and inspect it from a dashboard. It comes as a desktop app and
as a `konstruktor` command line tool that do the same things.

## Download

Konstruktor is available for Windows, macOS and Linux. Docker, or a Docker-compatible engine, is its
only dependency. Pick your platform below, or grab a build from the
[releases page](https://github.com/arkitektio/konstruktor/releases) on GitHub.

## Usage

How to install and run a hub with Konstruktor, in the app or from the terminal, is described step by
step in [I am starting new](/docs/introduction/installation/starting-new). If something does not
work, see [Troubleshooting the startup](/docs/troubleshooting/startup).
