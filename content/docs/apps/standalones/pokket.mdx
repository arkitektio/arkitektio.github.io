**Pokket** is your mobile gateway to the [Arkitekt](https://arkitekt.live) ecosystem. It serves as a companion app for managing your Arkitekt services, tasks, and connected devices directly from your phone.
For where it fits next to Orkestrator and when you would reach for it, see [Mobile Companion](/docs/introduction/mobile-companion).

## Features

### 🔗 Arkitekt Connection
Seamlessly connect to your Arkitekt instance. Pokket handles authentication via `lok` and provides a secure connection to your services.

### 📋 Task Management
Stay on top of your workflows. View and manage your latest tasks through the `rekuest` service integration, ensuring you never miss an important action.

### 📡 Device Provisioning
Easily provision ESP32-based devices for your lab or home. Pokket uses the **Improv Wi-Fi** protocol over BLE to configure devices with:
- Wi-Fi Credentials (Standard & Eduroam support)
- Arkitekt Connection Tokens

See [Embedded](/docs/developers/embedded) for the firmware side.

### 📶 Wi-Fi Profile Management
Manage your Wi-Fi configurations in one place. Save standard and Eduroam profiles to quickly provision multiple devices without re-entering credentials.

### 🕸️ Organisation Mesh
If your deployment runs an organisation [mesh](/docs/design/security/mesh), Pokket can join it once you approve it.
It runs its own in-app node (no VPN permission, no separate Tailscale app) and reaches the services that only
live on the mesh through it. The **Mesh** screen shows the node, the machines it sees, which services it carries,
and lets you switch it off.

## Install

| Platform | Where | Notes |
|---|---|---|
| **Android** | [`pokket.apk`](https://github.com/arkitektio/pokket/releases/latest/download/pokket.apk) | Open the link on the phone and install it (allow installs from your browser when asked). The [latest release](https://github.com/arkitektio/pokket/releases/latest) page has it too. |
| **iPhone / iPad** | [TestFlight](https://testflight.apple.com/) | Ask a maintainer to add you as a tester; you get an e-mail invite. Install TestFlight from the App Store and accept it. |

**Updates install themselves.** Most releases change only the app's JavaScript and arrive over the air:
Pokket downloads them on launch and offers a restart. You only need a new APK or TestFlight build when a
release changes the native app; the release notes say so.

## Development Setup

1. **Install dependencies**

   ```bash
   pnpm install
   ```

2. **Start the app**

   ```bash
   pnpm expo start
   ```

The [repository README](https://github.com/arkitektio/pokket) covers development clients, building the mesh
sidecar and how releases are made.

## Tech Stack

- **Framework**: React Native (Expo)
- **Styling**: NativeWind (Tailwind CSS)
- **Navigation**: Expo Router
- **Data**: Apollo Client (GraphQL)
- **BLE**: `react-native-ble-plx`
