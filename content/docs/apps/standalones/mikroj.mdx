---
title: MikroJ (deprecated)
description: MikroJ has been replaced by the native ImageJ Arkitekt plugin.
---

MikroJ, the Python app that wrapped Fiji through PyImageJ, is no longer maintained.

It has been replaced by the [ImageJ Arkitekt plugin](/docs/apps/standalones/imagej-plugin), a native Fiji plugin that runs directly
inside Fiji on Windows, Linux and Mac. Please head over to that page for installation and usage instructions.
