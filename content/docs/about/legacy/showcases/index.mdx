These worked examples used to be the **Showcase** section of this website. They were written for
older versions of Arkitekt, so the section has been taken down for now and the examples are kept
here.

The ideas still apply. The installer, the login, the connection flow, the channel names and the
code they show do not. [What's changed](/docs/about/legacy/whats-changed) explains how the
platform differs today.

## From the publication

The workflows described in the Arkitekt publication. They were run with the **Paper** version of
the platform, and are kept so that the publication's results can be reproduced. To follow them you
need a Paper deployment.

| Showcase | What it shows |
|---|---|
| [Smart Microscopy](/docs/about/legacy/showcases/smart-microscopy-workflow) | A no-code workflow for 3D live monitoring of cell clusters: segmentation, clustering and adaptive acquisition |
| [Streaming Analysis](/docs/about/legacy/showcases/streaming-workflow) | Real-time StarDist segmentation of 3D data while it is being acquired |
| [Interactive Workflow](/docs/about/legacy/showcases/interactive-workflow) | Napari, CARE denoising and Fiji combined to denoise and segment cells interactively |
