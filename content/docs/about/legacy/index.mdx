This section collects what the documentation still says about **older versions of Arkitekt**. None
of it describes how the platform works today. It is kept for three reasons: so that the results of
the original publication can be reproduced, so that old apps can be ported, and so that a name you
find in an old tutorial or repository can be looked up.

If you are new to Arkitekt, you do not need anything here. Start with
[joining a hub](/docs/use/joining), [starting your own](/docs/run/first-hub) or
[building an app](/docs/build/why-build).

## Which version is which

| Name | What it is | Status |
|---|---|---|
| **Paper** | The platform as it was for the original publication | Frozen. Still installable, to reproduce the results. |
| **`arkitekt-next`** | The Python package that came after it (`arkitekt_next`, `@register`, the `arkitekt-next` CLI) | Retired. Replaced by `arkitekt`. |
| **Next** / **`arkitekt`** | What the rest of these docs describe | Current |
